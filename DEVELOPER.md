# «Голос» (Holos) — руководство разработчика

Распознавание речи на компьютере, без интернета: запись с микрофона и звука компьютера, диктовка в любое окно по F8, расшифровка файлов, говорящие. Звук и текст не уходят с компьютера без явного действия человека — это главный принцип; каждую доработку сверять с ним.

## Запуск для разработки

```powershell
pip install -r requirements.txt
python main.py
```

`start.bat` — запуск без консоли (`pythonw`). Нужен `ffmpeg` в `PATH` или в `bin\` рядом с программой.

Модели в репозиторий не входят. Программа ищет их в `models\` (папка меняется в «Настройках»); скачать — вкладка «Модели» или установщик `Holos-Setup`.

Настройки и данные — в `data\` рядом с программой (`settings.ini`, база записей). В репозиторий не входят.

## Устройство

| Папка | Что там |
|---|---|
| `core/` | распознавание и логика без окон |
| `gui/` | окна на PySide6 (Qt) |
| `gui/tabs/` | страницы: записи, новая запись, диктовка, ассистент, файл, модели, настройки, о программе |
| `utils/exporter.py` | экспорт в TXT, SRT, JSON, Markdown |
| `installer/holos.iss` | установщик Inno Setup |
| `tools/` | сборка установщика, сравнение моделей, снимки окон для README |

Главные модули `core/`:
- `vosk_manager.py` — список моделей, выбор движка (Vosk Kaldi или sherpa-onnx).
- `sherpa_engine.py` — модели GigaAM, Parakeet, Vosk 0.54 на sherpa-onnx и onnx-asr.
- `mic_recorder.py`, `system_audio.py` — звук с микрофона и звук компьютера (WASAPI loopback).
- `dictation_manager.py` — диктовка по F8 в активное окно.
- `voice_commands.py` — голосовые команды «начать запись», «стоп запись», «пауза запись», «продолжить запись», «начать диктовку».
- `punctuator.py` — знаки и абзацы по паузам для моделей без своей пунктуации.
- `diarizer.py` — кто говорит (pyannote 3.0 + 3D-Speaker ERes2Net).
- `dictionary.py` — словарь пользователя: замены и горячие слова (заметка Markdown).
- `summary.py`, `assistant_target.py` — передача текста в окно Claude Desktop, только по кнопке или слову «Ассистент».
- `updates.py` — проверка новой версии на GitHub, только с согласия человека.
- `i18n.py` — интерфейс на русском, украинском, английском. Надписи в коде — русские, они же ключи перевода.
- `settings.py` — настройки и значения по умолчанию.

## Сборка установщика

```powershell
python tools\build_installer.py
```

Нужны Inno Setup 6 и `ffmpeg`. Выход — `Holos-Setup-<версия>.exe` (программа + модели) и `Holos-Update-<версия>.exe` (без моделей, ставится поверх). Номер версии — в одном месте: `core/updates.py`.
